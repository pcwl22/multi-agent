## 启用及默认值

`REPOPILOT_TASK_BUDGETS=false` 默认关闭，避免改变旧任务的恢复语义。设置 true 后只对新任务冻结 `REPOPILOT_BUDGET_LIMITS`：

| 字段 | 默认值 | 约束方式 |
| --- | --- | --- |
| wall_seconds | 900 秒 | 创建开始的绝对截止时间，节点/执行准入检查及 Docker 剩余超时 |
| model_requests | 20 | 外部调用前持久化占用；原生 LiveModel 每次结构化解析尝试单独计数 |
| observed_tokens | 200000 | 累计供应商已报告用量，响应返回后、写补丁前检查 |
| sandbox_runs | 10 | 修复候选和原始基线回放均计数；不可用/失败尝试也占额度 |
| artifact_bytes | 268435456 | 任务目录文件总大小的节点边界准入检查 |
| result_bytes | 8388608 | 每个容器 `/results` 的 tmpfs 内核容量上限 |

配置为受信后端 JSON；TaskRequest 不提供提高额度入口。历史任务读取持久化策略，进程重启和默认值变化不会重置额度。没有预算版本的旧任务维持原有行为。显式示例 Mock/其他受信自定义适配器按一次 generate 占一次请求额度；其内部调用由适配器负责，不冒称 Mock 实际联网。

## 持久化与终止

任务目录内独立 `budget.sqlite3` 将任务 ID、限额和截止时间绑定，执行前事务占用额度，完成后仅记录一次用量。额度不会随 LangGraph checkpoint 回退；账本缺失、绑定变化、未完成调用或未知 Token 用量均拒绝自动重放。已观测时间高水位和进程内单调时钟防止普通时钟回拨恢复额度，不宣称抵抗恶意本地账本/系统时钟修改或备份回滚。

耗尽进入 `budget_exhausted`，通过 budget_failure 保留资源名与原因；已有 Diff、候选、日志和事务现场不删除。普通 resume 拒绝继续，不自动扩大额度、重置任务或发布。`GET /api/tasks/{id}/budget` 和 UI 面板提供限额、剩余时间、占用次数、Token 完整性及未完成请求数。已完成修复后的人工审批/发布不再次消耗执行预算。

补丁响应返回后立即复核预算，超时/Token 超限不会继续应用该补丁。两个新增用例先在实现收紧前失败，修复后均通过，证据见外部 test-results.json 中 postresponse_before/after。已完成补丁不因后续耗尽被回滚。

## Docker 资源边界

预算模式移除可写宿主 `/results` 挂载，使用限额 tmpfs；保留网络禁用、512 MiB 内存/交换限制、1 CPU、64 PID、非 root、只读仓库和根目录、cap-drop 及 no-new-privileges。宿主只经有限尾缓冲读取最多 2 MB JUnit，输出仍持续排空并限长保留，报告缺失/过大停止任务。

Docker 宿主超时按任务剩余时间缩短；固定容器包装器也给预定义 pytest 子进程设置超时。宿主进程退出后容器内看门狗仍会退出并结束测试；finally 清理另最多等待 10 秒。容器命令来自固定允许列表，不接收模型 Shell。

## 未验证与能力边界

- 本轮未新增真实 LLM 调用或产品发布链路验收；本提交的新 GitHub Python 3.11/3.13、Docker CI 仍待审批后更新并读取。没有借用旧提交的 CI 绿色。
- Token 是已观测用量阈值，不是预付费/计费硬上限；一次请求的输入开销可能越过阈值。单次输出最多请求 4096 Token，且受剩余额度进一步收紧，供应商计费仍以供应商记录为准。
- 网络超时是传输层超时，节点截止时间为协作检查；不能强制中断任意受信自定义模型、每个持续 SSE 流或任何 Python 内部操作。Docker 有独立子进程超时。这不是整台机器累计 CPU/内存调度器。
- 任务现场文件大小在边界检查，允许单个操作在检查前增长；不包含共享 tasks/checkpoint SQLite、其他任务或整盘的硬配额。真正内核硬容量限制仅用于预算容器结果 tmpfs，旧的非预算模式继续原行为。
- 进程退出测试不等于断电、文件系统损坏、恶意同机进程或所有容器/网络故障的穷尽验证。新 UI 面板未单独开展浏览器交互验收。
