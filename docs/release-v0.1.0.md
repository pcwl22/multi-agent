# v0.1.0 release preparation

Status: local release candidate; no tag, GitHub Release or package publication has
been performed. Exact validation results and artifact hashes are recorded after
the current staged acceptance finishes.

## Clean environment

Requirements: Python 3.11 or later, Git, Docker Engine/Desktop with Linux
containers. Windows commands use PowerShell 7. Clone the reviewed code into a
fresh folder, then run:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.lock
python -m pip install --no-deps -e .
docker build -t repopilot-sandbox:local -f sandbox/Dockerfile .
$env:REPOPILOT_RUN_DOCKER_TESTS = '1'
python -m pytest -q
python -m ruff check .
python scripts/start_demo.py
```

For an actual provider session, stop the prior launcher, then run:

```powershell
python scripts/start_demo.py --live --model deepseek-v4.1-flash --base-url https://muyuan.do/v1
```

The launcher asks for the key with hidden input if it is absent from the process
environment. Only the API child receives it. UI and API bind to loopback; Ctrl+C
stops both children. Provider model availability and request limits depend on the
configured service. The default 7.5-second pacing is process-local; other app
processes using the same key must be coordinated separately.

GitHub publishing remains disabled unless a fixed repository and credential are
configured. Review the exact diff, approve its digest, then explicitly request a
draft PR. Approval alone does not publish; publication does not merge.

## Expanded pilot

Set live model variables as documented in the README and supply the credential
with hidden input. Run a fresh output directory:

```powershell
$env:REPOPILOT_REPOSITORY_ROOT = 'app/evaluation/expanded/repos'
$env:REPOPILOT_MODEL_MIN_INTERVAL = '7.5'
python -m app.evaluation.runner --dataset app/evaluation/expanded/dataset.json --repeats 3 --workers 3
```

Every case has a failing independent baseline and hidden holdout. All provider
errors remain in the raw attempts and denominator. Multiple workers share CPU
and pacing, so duration is not an intrinsic algorithm-speed comparison.

Controlled feedback demonstration (separate from benchmark metrics):

```powershell
python -m app.evaluation.feedback --output .repopilot/feedback-live-demo
```

This explicitly replaces the first/all model candidates with deliberately bad
code. It demonstrates reaction to actual container failures and finite stopping;
it does not claim those candidates were naturally generated by the model.

## Packaging and scope

```powershell
python -m build --no-isolation
```

The wheel includes the evaluator corpus and acceptance tests. Keep evaluation
references outside repair workspaces. Source archives include frontend, sandbox,
tests, scripts and docs. Docker images are built separately; they are not bundled
inside the wheel. Use the source distribution for the browser demo.

Supported: bounded text snapshots, Python edits and added tests, fixed pytest
entry point, prebuilt dependencies, local API/UI and explicit draft PRs.
Unsupported/unverified: arbitrary build systems, dynamic dependency installation,
linked Git worktrees in the MCP Git tool, networked repository tests, public
multi-user serving, distributed task queues and LangSmith upload.
