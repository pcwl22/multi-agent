## 已实现

- 最多 8 层允许列表异常链和连接/读取/代理/协议等阶段，保留本地产生的逐次标识与耗时，不记录异常文字、URL、头或服务端错误正文。
- live 评测批次共享发送前门控，默认连续 3 次同类/同阶段失败停止新准入，认证拒绝立即停止；0 显式禁用。已准入请求可结束和记账，打开后不自动复位。
- 所有计划单元保留，未执行与真实失败分开；历史主指标分母不缩减，通用报告另列完整计划成功率。
- 保留旧 budget_exhausted/resource 契约，新增 kind 区分额度阈值、用量未知、发送未确认和账本异常；界面按原因解释。预算启用时未知状态和未完成预留继续阻止重放；batch_paused 任务终止后不能通过重启绕过。
- 证据写入失败也停止新发送，不丢弃已完成响应的用量。门控是批次进程内机制，不是跨进程全局协调器或可恢复调度器。
